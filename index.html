Selected systems

01 OneRail · AI Systems · Platform

AI Agent Platform

A platform that spawns specialist AI agents to take on real engineering work, reachable through webhooks, Slack, and GitHub. Each agent runs in its own sandboxed container, deployed from a Kubernetes manifest, with zero standing permissions: a virtual key grants scoped MCP access to the data its job requires, and the key dies with the job.

Every new agent gets its own scoped key, so it can only ever reach what its job needs. Each one is created on demand for the single job in front of it, and nothing more.

Agents · MCP · Kubernetes · Slack · GitHub

02 OneRail · Developer Experience · CI/CD

Feature Preview Environments

Open a pull request on a feature/ branch and a live container of that branch appears online, wired into staging. Open PRs in other repos under the same branch name, and the containers discover each other and interconnect automatically. Merge, and it all tears down on its own.

In a system with dozens of repos, that meant demoing a feature before it ever touched main, let alone production.

Containers · GitOps · Multi-repo · Staging

03 OneRail · Observability · OpenTelemetry

Observability Platform

OpenTelemetry APM built around a central collector: every service ships its traces, logs, and metrics to one place, in the same shape, so nothing downstream has to guess who sent what. Tail sampling keeps the traces that matter and drops the noise, so latency, errors, and throughput read the same way across the whole system.

Cheap enough to leave on everywhere, and already the reason behind dozens of bug fixes and performance wins.

OpenTelemetry · Traces · Logs · Metrics · Tail sampling · Collector

04 Microsoft · Mobile · Accessibility

Dynamics 365 Field Service Calendar

Brought Outlook-grade calendar UX to Dynamics 365 Field Service on mobile and desktop: three calendar views and booking pages working across browsers, Android, and iOS, with full screen-reader support. Offline mode was the hard part: field technicians lose signal constantly, so the calendar had to keep working alone and reconcile when the connection came back. I also built the CI/CD pipelines behind it and worked from Figma alongside the design org to hold the accessibility bar, all inside a codebase serving enterprise customers at Microsoft scale.

React · Offline-first · Accessibility · CI/CD

05 Ace Hardware · Platform · Marketplace

Ace Senior Services

Led the creation of the gig-economy platform that became Ace Home Services: customer, servicer, and admin surfaces, built by three full-stack teams under my lead. A large share of the deliverable work was designed or built by me personally: two of the three surfaces end to end, Stripe payments, Azure auth, accessibility testing, responsive UX. Along the way I introduced Azure Boards and an agile workflow to the company.

Stripe · Azure · Accessibility · Agile

AI research · 2026

A proof of concept inspired by Jev: I trained an open-weight language model with LoRA to return yes-or-no judgments, choices, and scores from answer-token probabilities. L·02

Since 2017

OCR systems, classifiers, and a pile of side experiments, most of it built on my own time, and a good chunk of it ended up running in production. University of Washington certificates in Data Science and Machine Learning made it official.

L·03

Refinement

Civilization simulator

A computer-vs-computer civilization simulation, basically an ant farm to watch with friends. Runs are simulated ahead of time, compressed, and streamed in chunks over websockets; every viewer's frame is synchronized to the clock, so the whole room watches the same moment together. Neo-retro shell, chatroom included.

L·04

Custom Operating System

Low-level

An operating system mirroring Linux's capabilities: terminal commands, process scheduling, memory allocation, a file system, hardware interfacing, plus semaphore locks and user privileges. Debugging at this level is brutal, and no project taught me more about how software actually works.

L·05

Verilog Neural Network

Hardware · Senior design

A neural network implemented in hardware description language: a sigmoid approximation drawn from academic papers for the activation function, and high-precision floating point written from scratch. Simulated neurons matching an equivalent software model. My greatest hours-per-insight challenge to date.
