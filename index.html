AI Systems · Platform

OneRail

AI Agent Platform

A platform that spawns specialist AI agents to take on real engineering work, reachable through webhooks, Slack, GitHub, and other interfaces. Every agent runs in a container with zero standing permissions — each carries only a virtual key that unlocks scoped MCP access to exactly the information its job requires, and nothing else.

Security posture and capability scale together — some of the work I'm proudest of.

02

Developer Experience · CI/CD

OneRail

Feature Previews

Open a pull request on a feature/ branch and a live container of that branch appears online, wired into staging. Open PRs in other repos under the same branch name, and the containers discover each other and interconnect automatically. Merge, and it all tears down on its own.

In a many-repo system, features became testable and demoable long before they could touch a major branch — or production.

  • GitOps
  • Multi-repo
  • Staging

03

Observability · OpenTelemetry

OneRail

Observability Platform

OpenTelemetry-based APM through a central collector system: every service exports to one place, and tail sampling keeps the traces that matter while dropping the noise. One pipeline — one shared language for latency, errors, and throughput across the entire system.

Observability the whole engineering org can afford to leave on.

  • OpenTelemetry
  • APM
  • Tail sampling
  • Collector

AI Infrastructure

OneRail

AI Gateway

A single front door for the engineering department's LLM traffic. The gateway routes each prompt to the model best suited for it — balancing capability, latency, and cost per request, so teams get the right intelligence without re-solving model selection project by project.

Model choice became an infrastructure concern instead of a per-team gamble.

  • LLM routing
  • Gateway
  • Cost & latency

Independent Work

Nights-and-weekends engineering. I've been building my own ML models since 2017 — long before it was the safe thing to do.

Machine Learning, from scratch

Since 2017

OCR systems, classifiers, and a long tail of experiments — built on my own time, with much of it feeding back into production work. Formalized along the way with University of Washington certificates in Data Science and Machine Learning.

Refinement

Civilization simulator

A computer-vs-computer civilization simulation — effectively an ant farm to watch with friends. Runs are computed ahead of time, compressed, and streamed in chunks over websockets; every viewer's frame is synchronized to the clock, so the whole room watches the same moment together. Neo-retro shell, chatroom included.

Custom Operating System

Low-level

An operating system mirroring Linux's capabilities: terminal commands, process scheduling, memory allocation, a file system, hardware interfacing — plus semaphore locks and user privileges. Debugging at this level is brutal, and no project taught me more about how software actually works.

Verilog Neural Network

Hardware · Senior design

A neural network implemented in hardware description language: a sigmoid approximation drawn from academic papers for the activation function, and high-precision floating point written from scratch. Simulated neurons matching an equivalent software model — my greatest hours-per-insight challenge to date.
